- 2026-11-19 [ステップ1] create-expo-app のテンプレートに含まれていた Expo 社の LICENSE ファイルは削除した。このアプリのライセンスはオーナーが決める。
- 2026-11-19 [ステップ2] サーバーの時刻差し替えは `app.now_override`（トランザクション内の設定）で行い、`app_settings.allow_clock_override = true` の環境でだけ有効にする。本番は false。
- 2026-11-19 [ステップ2] クライアントの day_key 計算は、日本に夏時間が無いため UTC+9 の固定値で行う（表示用。判定はサーバー）。
- 2026-11-19 [ステップ2] 開発用 seed のお題30件は「今日の3日前」から並べ、ジャンルを5つの柱の順に回す。
- 2026-11-19 [ステップ3] 「締め切り」は翌 6:59:59（含む）。新規タイマーは 6:49:59 まで開始でき、6:50:00 から CLOSED。
- 2026-11-19 [ステップ3] 7:00 を過ぎても、前日のタイマー終了から猶予時間内で手紙を読み終えていなければ、前日の流れを続ける（猶予が切れたら新しい日に切り替わる）。
- 2026-11-19 [ステップ3] お題が未入稿の日はタイマーを開始できず、ホームに「まだ届いていません」と表示する。
- 2026-11-19 [ステップ3] アプリのホームはサーバーの get_today_state() だけを見て画面を切り替える。どの画面を直接開いても、状態に合わない画面ならホームの判定に従って移動する。
- 2026-11-19 [ステップ3] タイマーのアニメーションは Lottie ではなく Reanimated で描いた。デザイナーの素材ができたら Lottie に差し替える。
- 2026-11-19 [ステップ3] 状態の取り直しは、タイマー終了・回答受付の終了・新規タイマー受付の終了・7:00 のうち最も早い時刻と、アプリが前面に戻ったときに行う。
- 2026-11-19 [ステップ4] 文字数は前後の空白（全角スペース・改行を含む）を除き、コードポイント単位で数える（サーバーの char_length と同じ。絵文字の異体字セレクタも1字）。
- 2026-11-19 [ステップ4] 却下（rejected）された回答は、受付時間内なら本文を直して再投稿できる。投稿済みとはみなさないため、手紙は読めない。
- 2026-11-19 [ステップ5] 審査の順番は「自傷の兆候 → 個人情報 → NG ワード → AI → 承認」。自傷の兆候は他の理由より優先して crisis にする。
- 2026-11-19 [ステップ5] 審査はアプリが投稿直後に Edge Function を呼び、取りこぼしは5分ごとの定期実行で拾う。審査は冪等なので誰が呼んでも安全。
- 2026-11-19 [ステップ5] AI 審査はサービス未決定（§14）のため、差し替え口だけを用意し、既定では使わない。AI の呼び出しに失敗したら審査待ちのまま残す。
- 2026-11-19 [ステップ5] crisis の回答をした人も、相談窓口の案内を見たあとは手紙を読める（案内は1日1回、端末で記録）。
- 2026-11-19 [ステップ5] 通報の理由は「人を傷つける内容／個人情報／書いた人が心配／宣伝・勧誘／その他」。運営の手紙（seed）はブロックの対象外。
- 2026-11-19 [ステップ5] ブロックは今日すでに届いた手紙は消さず、以後の割り当てから除外する。
