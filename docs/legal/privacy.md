# プライバシーポリシー

最終更新: 2026年11月19日（下書き）

> 下書きです。公開前に内容の確認が必要です。

## 1. 取得する情報

・アカウント識別子（端末ごとに作られる、名前のない ID）  
・回答の本文、選んだ思考時間、回答の日時  
・共感・報告・ブロックの操作  
・通知の設定と、通知を送るためのトークン（許可した場合）  
・連携した場合、Apple / Google アカウントの識別子とメールアドレス  
・広告の配信に使う情報（広告 ID など。許可した場合）  
名前・住所・電話番号などは取得しません。

## 2. 使う目的

・問いを届け、回答を他の利用者に名前を伏せて届けるため  
・不適切な投稿を防ぎ、安全に使ってもらうため（自動の審査を含みます）  
・通知を送るため  
・広告を表示するため  
・サービスの改善のため（継続率などの集計。回答の本文は分析に使いません）

## 3. 他の利用者に見えるもの

回答の本文だけが、名前や ID を伏せて、同じ問いに答えた最大10人ずつの利用者に届きます。共感の数、誰が共感したか、誰が書いたかは、誰にも表示されません。

## 4. 第三者への提供・委託

法令に基づく場合を除き、本人の同意なく第三者に提供しません。サーバーの運用・通知・広告のために外部のサービスを利用します（「外部送信に関する公表事項」を参照）。

## 5. 心配な内容への対応

自分を傷つけるおそれのある内容が書かれていると判断した場合、その回答は他の利用者に届けず、本人に相談窓口をご案内します。

## 6. 保存期間と削除

回答はアカウントを削除するまで保存します。アーカイブから個別に削除した回答は、他の利用者にも表示されなくなります。アカウントを削除すると、すべての情報を消去します。
